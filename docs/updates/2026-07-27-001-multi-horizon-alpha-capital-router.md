# 多周期 Alpha 资本路由与核心-卫星资金决策

发布日期：2026-07-27

## 1. 为什么这是平台主链的大功能

上一版本已经能对 A 股、港股、美股和基金形成经过历史样本外校准、真实前瞻再放行的多周期概率，但概率实验室仍然与资金决策链隔离：

1. `decision_eligible` 只能说明某个预测事实具备进入决策层的资格，不能直接回答应该保留多少现金；
2. 5/20/60 日股票概率和 20/60/120 个确认净值观察的基金概率高度相关，不能当成三张独立选票；
3. 相同资产可能出现在多个预登记项目中，重复模型不能因为创建了多个项目而提高仓位；
4. 正向概率必须经过投资期限、市场权限、集中度和全组合风险约束，负向概率也不能被误解为自动做空；
5. 新基金没有当前组合穿透暴露，不能仅凭概率直接产生申购金额；
6. 已有“机会策略收益实验室 → 投资委员会 → 全组合资金计划”使用的是成本后前瞻收益证据，不能与概率边际简单相加。

本次增加的不是另一张“荐股榜”，而是连接概率与全组合资金引擎的独立治理层：

```text
预登记 Alpha 项目
  → 历史样本外概率门禁
  → 真实前瞻 6 批 / 30 条再放行
  → 最新运行、新鲜度、来源和完整性检查
  → 相对各模型自身基准胜率的概率边际
  → 固定可靠性收缩
  → 多周期正向 / 负向 / 冲突 / 中性共识
  → 同资产同模型族去重
  → 核心 / 卫星 / 现金模型路线
  → 用户明确确认后冻结不可变指令
  → 全组合资金引擎 v5 二次约束
  → 投资政策、已有仓位行动、穿透暴露、集中度和压力测试
  → 有上限的人工研究金额，仍不生成订单
```

功能提高的是资金决策的一致性、可审计性和主动弃权能力，不保证盈利。

## 2. 同行与专业方法调研

本次设计参考了公开的专业产品结构，但没有照搬任何平台的交易授权：

- QuantConnect 的 [Alpha Framework](https://www.quantconnect.com/docs/v2/writing-algorithms/algorithm-framework/alpha/key-concepts)把观点的资产、方向、周期、幅度与置信度表达为 Insight；其 [Portfolio Construction](https://www.quantconnect.com/docs/v2/writing-algorithms/algorithm-framework/portfolio-construction/key-concepts)再把多个 Insight 转换为目标组合。平台因此把“概率事实”和“组合构建”分成两个引擎，预测组件本身不能拥有资金权限。
- Interactive Brokers 的 [Model Portfolios](https://www.interactivebrokers.com/en/trading/model-portfolios.php)使用目标百分比和再平衡管理模型组合。本平台也保存目标权重和漂移，但不会连接 IBKR/Futu 或把目标转换成订单。
- Numerai Signals 的 [Scoring](https://docs.numer.ai/numerai-signals/scoring/)同时观察不同时间跨度和模型的相对贡献，[Meta Portfolio Contribution](https://docs.numer.ai/numerai-signals/scoring/meta-portfolio-contribution-mpc)强调模型对组合的独立增量价值。本平台据此禁止同模型族重复项目重复投票，并在方向不一致时升级为冲突，而不是平均掉风险。
- Betterment 对[组合漂移](https://www.betterment.com/help/portfolio-rebalancing)使用各目标权重绝对偏差之和的一半，并把现金纳入漂移。本平台采用相同的单边换手结构，但固定 10% 仅触发人工复核，不自动再平衡。
- BlackRock Aladdin Risk 的[全组合风险视图](https://www.blackrock.com/aladdin/platforms/products/aladdin-risk)强调从证券、行业、因子和组合层做暴露分解、情景与压力分析。本平台因此没有让 Alpha 路由绕过已有全组合压力测试；概率路线只是上游候选和否决证据。

这些参考共同指向一个原则：**信号、组合构建、风险和执行必须分层**。本功能只完成前两层之间的受控桥接，风险层仍有最终否决权，执行层仍关闭。

## 3. 两个独立引擎

### 3.1 Alpha 资本路由

- 结果 Schema：`alpha_capital_route.v1`
- 引擎：`multi_horizon_alpha_capital_router@1.0.0`
- 全组合 Alpha 试投硬上限：组合价值的 `2%`
- 单候选 Alpha 模型权重硬上限：`20%`
- 不搜索阈值、周期权重、可靠性权重或核心/卫星比例

### 3.2 全组合资金决策

- 结果 Schema 保持：`portfolio_capital_decision.v1`
- 引擎由 `whole_portfolio_next_best_action.v4` 升级为 `whole_portfolio_next_best_action.v5`
- 全局人工研究上限仍为组合价值的 `5%`
- Alpha 路线自身仍受更严格的 `2%` 袖套上限
- 机会策略和 Alpha 同时支持同一资产时取较大研究需求，不相加
- Alpha 负向或冲突共识可以否决机会策略新增，但不能创建空头

## 4. 哪些概率有资格进入路由

每个资产周期必须同时满足：

1. 项目处于 `active`；
2. 项目政策 SHA-256 和完整性通过；
3. 最新 Run 为 `succeeded` 或 `partial` 且输入/结果完整性通过；
4. 项目仍保持股票 5/20/60 或基金 20/60/120 的冻结周期契约；
5. 最新 Run 没有过期：股票至少使用 14 天或两倍运行频率中的更宽边界，基金至少使用 45 天或两倍运行频率中的更宽边界；
6. 该预测历史门禁通过；
7. 该预测在运行开始前已经通过真实前瞻门禁；
8. 当前前瞻 Scorecard 对该周期仍为 `decision_eligible`；
9. 资产和基准的数据来源仍满足决策来源等级；
10. 发布概率和冻结基准胜率均存在。

任一条件失败的周期不会被降级成弱信号，也不会使用 shadow 概率替代。

## 5. 不与 50% 生硬比较

每个模型有自己的冻结基准胜率。路由使用：

```text
原始概率边际 = 校准概率 - 该预测的冻结基准胜率
```

例如基准胜率为 62%、校准概率为 68%，边际是 `+6pp`，而不是错误地解释为“比 50% 高 18pp”。方向阈值固定为：

- `>= +5pp`：正向；
- `<= -5pp`：负向；
- 中间区域：中性。

该边际不是预期收益率，不能用于计算未来利润。

## 6. 固定可靠性收缩

达到前瞻最低门槛不代表 30 条结果与 300 条结果同样可靠。系统把六项前瞻证据压缩到 `[0,1]`：

| 因子 | 满额参考 | 固定权重 |
| --- | ---: | ---: |
| 成熟 outcome | 60 | 25% |
| 独立运行日期 | 12 | 15% |
| 资产覆盖 | 8 | 10% |
| Brier Skill | 0.10 | 25% |
| ECE 校准改善 | 0.00 最佳、0.12 归零 | 15% |
| 逐批优于基准比例 | 1.00 | 10% |

```text
有效概率边际 = 原始概率边际 × 固定可靠性
```

所有权重和满额参考都写入不可变证据；没有根据当前候选表现自动调参。

## 7. 多周期共识与重复模型治理

### 7.1 共识

- 至少两个合格周期均达到 `+5pp`：`supportive`；
- 至少两个合格周期均达到 `-5pp`：`defensive`；
- 同时存在有意义的正向和负向周期：`conflict`；
- 只有一个合格周期：`collecting`；
- 两个以上周期但方向强度不足：`neutral`。

只有 `supportive` 能获得模型权重。`defensive` 和 `conflict` 进入新增资金否决清单；`neutral` 与 `collecting` 保持观察。

### 7.2 同模型族不重复计票

同一资产出现在多个项目时，系统按以下固定顺序选择规范证据：

1. 合格周期数；
2. 加权可靠性；
3. 有效边际绝对值；
4. Run 新鲜度；
5. 稳定项目 ID。

其他项目保存为 `duplicate_programs_excluded`。如果重复项目在正向与负向之间不一致，规范结论直接变为 `conflict`，不会挑选更乐观的结果。

## 8. 核心、卫星和现金

股票 60 日属于核心周期，5/20 日属于卫星周期；基金 60/120 个确认净值观察属于核心，20 个观察属于卫星。资产的正向有效边际由哪类周期贡献更多，就进入哪一袖套。

投资政策期限映射固定为：

| 用户期限 | 核心目标 | 卫星目标 |
| --- | ---: | ---: |
| 短期 `short` | 40% | 60% |
| 中长期 `mid_long` | 70% | 30% |
| 长期 `long` | 85% | 15% |

广度约束：

- 1 个正向候选：模型最多投入 35%；
- 2 个正向候选：模型最多投入 60%；
- 3 个及以上：模型最多投入 100%；
- 单候选仍不得超过 20%，因此 1 个候选的实际投入最多是 20%；
- 缺少某个袖套候选时，该袖套预算保留现金，不转给另一袖套；
- 剩余权重明确保存为 `CASH`，不强制满仓。

同一袖套内仅按收缩后的有效概率边际排序和分配，不把它称为预期收益。

## 9. 基金资金桥

基金概率可以进入模型路线，但资金桥分两层：

- 已有基金：只有真实持仓仍存在，且当前穿透暴露快照完整性、决策资格、估值绑定和该基金 `loaded` 状态全部通过，才可进入全组合追加复核；
- 新基金：固定为 `new_fund_due_diligence_only`，模型可以显示，但新增金额为 0；
- 暴露过期或不完整：固定为 `fund_exposure_not_verified`；
- 任何基金最终仍受单品、权益、行业和压力情景约束。

这样避免为从未持有的新基金凭空假设行业和权益暴露。

## 10. 与机会策略资金链的合并规则

全组合资金引擎 v5 同时读取：

- 已冻结的机会策略收益记分卡和投资委员会结果；
- 已冻结、完整性通过、与当前投资政策/持仓/Alpha 证据一致的 Alpha 资本指令。

合并规则：

1. 同一资产被两条证据链支持时，研究需求金额取 `max`，不求和；
2. 当前有效的 Alpha `defensive/conflict` 对机会候选添加 `alpha_probability_veto:*`；
3. 没有正向 Alpha 候选但存在负向证据时，可冻结 `abstained` 现金/否决指令，它仍能进入资金引擎执行否决；
4. Alpha 候选金额先受 2% 袖套上限，再受全局 5% 上限；
5. 已有仓位要求减仓、风险复核或持有逻辑复核时，继续优先于任何新候选；
6. 估值、穿透、单品、权益、行业或压力情景门禁失败时，最终金额仍为 0；
7. 所有结果 `execution_authorized=false`。

## 11. 漂移

路线把全部候选和现金一起计算：

```text
单边换手 = 0.5 × Σ |当前目标权重 - 上次冻结目标权重|
```

- 首次冻结只建立基线；
- 单边换手达到 `10%`，或候选发生进入/退出，状态为 `review`；
- 漂移带内为 `within_band`；
- 漂移只触发人工复核，不生成再平衡交易。

## 12. 不可变存储与 API

新增表 `alpha_capital_mandates`：

- `tenant_id + user_id` 隔离；
- 保存 actor、Schema、引擎、状态、投资政策版本、证据截止时间；
- 证据 JSON / SHA-256 与结果 JSON / SHA-256 双哈希；
- 结果必须反向绑定证据 SHA-256、投资政策版本和顶层状态，证据/结果 Schema 与引擎版本也必须一致；
- 相同用户、引擎和证据内容寻址幂等；
- SQLite 与 PostgreSQL 均拒绝 UPDATE/DELETE；
- 迁移：`alpha-capital-router.v1`；
- readiness：`alpha_capital_schema`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/alpha-capital` | 当前实时路线、漂移和冻结绑定 |
| POST | `/api/v1/alpha-capital/mandates` | 确认证据摘要后冻结 |
| GET | `/api/v1/alpha-capital/mandates` | 不可变历史 |
| GET | `/api/v1/alpha-capital/mandates/{mandate_id}` | 完整证据、结果和完整性 |

冻结请求必须同时提交当前 64 位证据 SHA-256 和 `research_only_acknowledged=true`。证据在读取和提交之间变化时返回 `409`，用户必须刷新后重新确认。只有 `paper_ready` 和带否决信息的 `abstained` 可以冻结；`blocked/collecting` 即使绕过前端直接调用 API 也会失败关闭。

## 13. 前端工作台

“研究中心 → 概率实验室”顶部新增完整资本路由工作台：

- 路由状态、正向候选、否决数、模型投入、现金和 2% 全组合硬上限；
- 核心/卫星/现金可视化；
- 原始概率边际、可靠性收缩后边际、合格周期、模型目标和基金资金桥；
- 负向/冲突否决清单；
- 五项路由门禁和完整说明；
- 明确勾选“仅研究、非订单”后冻结；
- 当前证据、截止时间、漂移和执行边界；
- 不可变历史、结果/证据摘要和完整性。

宽表仅在自身区域滚动；桌面和移动端均保留明确现金与弃权状态。

## 15. 已知边界

- 可靠性收缩是固定治理函数，不是经过实时最优化的贝叶斯后验；
- 多周期仍共享同一资产和模型家族，相关性无法完全消除；
- 概率边际不是预期收益率，模型权重也不是最优 Kelly 仓位；
- 核心/卫星比例来自用户投资期限，不代表资产类别战略配置建议；
- 新基金必须先完成尽调和穿透，不会直接获得金额；
- 日线模型不处理盘中冲击、涨跌停排队、整手、停牌和真实券商可用现金；
- 2%/5% 是研究上限而非最低投入，系统可以保留 100% 现金；
- 市场结构、数据源和模型有效性会变化，已冻结指令也可能立即过期；
- 不连接券商、不生成股数、不自动下单、不做空、不加杠杆、不保证盈利。
